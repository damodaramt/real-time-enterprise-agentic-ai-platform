# Vector Database

## Introduction

A vector database is a specialized database designed to store, index, and search high-dimensional vectors generated by machine learning models. Unlike traditional databases that search using exact text matches, vector databases perform semantic search by comparing the similarity between vectors.

In this project, PostgreSQL with the pgvector extension serves as the vector database for Retrieval-Augmented Generation (RAG).

---

# Why Vector Databases?

Traditional SQL databases perform exact matching.

Example

Query

Docker networking

Traditional Search

Looks for the exact words "Docker" and "networking".

Vector Search

Finds documents discussing container communication, bridge networks, overlay networks, and container connectivity even if the exact words are different.

Benefits

* Semantic understanding
* Fast similarity search
* High retrieval accuracy
* Scalable document retrieval
* Foundation for enterprise RAG

# What is a Vector?

A vector is a list of numbers representing the semantic meaning of text.

Example

Text

FastAPI is a high-performance Python framework.

Embedding

[0.214, -0.441, 0.623, ...]

Documents with similar meanings produce vectors that are close together.

---

# Similarity Metrics

## Cosine Similarity

Most commonly used for text embeddings.

Measures the angle between vectors.

Advantages

* Works well with normalized embeddings
* High semantic accuracy

---

## Euclidean Distance

Measures the straight-line distance between vectors.

Useful for numerical feature vectors.

---

## Inner Product

Measures similarity using the dot product.

Often used with normalized embeddings.
